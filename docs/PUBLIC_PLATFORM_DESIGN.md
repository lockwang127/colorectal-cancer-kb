# Public Platform Design

This document is retained as a historical note.

The earlier public Q&A assistant concept has been replaced by the current lock2.wang direction:

- personal research and technology sharing
- colorectal cancer knowledge engineering
- downloadable structured knowledge resources
- local Python query module
- Agent Skill examples
- RAG and workflow prototypes

The current platform does **not** target patient-facing online consultation, registration-first access, or individualized medical advice.

Current public entry:

- [https://lock2.wang](https://lock2.wang)

Current priority:

1. Keep the colorectal cancer knowledge base traceable and versioned.
2. Provide direct downloads for users who cannot access GitHub reliably.
3. Support RAG and Agent prototyping with local-first resources.
4. Maintain clear medical, privacy and evidence boundaries.

For implementation details, use the lock2.wang project documentation and the release workflow rather than this historical concept.
