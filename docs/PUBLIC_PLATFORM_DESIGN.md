## 三、功能架构

### 3.1 普通用户端

| 功能模块 | 描述 | 技术实现 |
|----------|------|----------|
| **智能问答** | 自然语言问答，实时生成答案 | RAG + LLM |
| **知识检索** | 结构化检索指南、药物、方案 | 向量搜索 |

| **收藏分享** | 收藏问答，生成分享卡片 | 社交分享 |

| **审核管理** | 审核新增知识质量 | 工作流引擎 |
| **版本控制** | 知识库版本管理 | Git-style |
| **数据分析** | 用户问答数据分析 | 统计面板 |
