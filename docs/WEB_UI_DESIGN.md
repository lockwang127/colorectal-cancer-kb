## 六、技术组件清单

| 组件 | 技术方案 | 说明 |
|------|----------|------|
| **前端框架** | Next.js 14 | App Router + Server Components |
| **样式** | TailwindCSS + shadcn/ui | 现代UI组件库 |
| **认证** | NextAuth.js | 邮箱+密码认证 |
| **LLM对话** | DeepSeek-V3 / GPT-4o | 医疗问答 |
| **向量检索** | Qdrant Cloud | 知识库检索 |
| **RAG编排** | LangGraph | 多步骤推理 |
| **数据库** | PostgreSQL | 用户数据 |
| **部署** | Vercel | 前端托管 |
| **API** | FastAPI | 后端服务 |

## 七、API接口设计

```bash
# 用户认证
POST   /api/auth/register     # 注册
POST   /api/auth/login        # 登录
GET    /api/auth/me           # 当前用户

# 问答
POST   /api/chat              # 发送问题
GET    /api/chat/history      # 对话历史

# 知识库
GET    /api/knowledge         # 获取知识列表
GET    /api/knowledge/:id     # 知识详情
POST   /api/knowledge         # 团队：添加知识

# 管理（团队端）
POST   /api/admin/import      # 批量导入
POST   /api/admin/approve     # 审核通过
GET    /api/admin/stats       # 统计数据
```
